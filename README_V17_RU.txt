UFILAG v17 — исправление изображений страницы игры

Что исправлено:
1. Страница sector-7.html теперь обновляет не только верхний баннер, но и большую обложку в блоке «Проект».
2. Баннер из game_settings.banner_url отображается в верхнем блоке.
3. Обложка из games.cover_url отображается в блоке обложки игры.
4. Если заполнено только одно из двух полей, изображение используется в обоих блоках — поэтому изменение видно на странице игры.
5. Если Supabase временно недоступен, показывается встроенная новая иллюстрация больницы без надписей.

Установка:
- Замените ВСЕ файлы сайта файлами из этого архива, включая папку assets. Не загружайте только sector-7.html.
- В админке откройте «Материалы игр», выберите Sector 7.
- Для большого изображения в блоке игры используйте «Обложка / изображение игры» → «СОХРАНИТЬ ОБЛОЖКУ».
- Для верхнего широкого блока используйте «Баннер игры» → «СОХРАНИТЬ БАННЕР».
- После загрузки откройте страницу игры и сделайте Ctrl+F5.

Новых SQL-миграций нет. Проверены синтаксис JavaScript и целостность архива. Реальное сохранение в Supabase зависит от Storage/RLS и должно быть проверено на вашем проекте.
