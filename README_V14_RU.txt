UFILAG v14 — установка

1. Сделайте резервную копию текущей папки сайта.
2. Распакуйте UFILAG v14 и замените файлы сайта.
3. В Supabase SQL Editor выполните SUPABASE_V14_HERO_LINKS_GAME_EDITOR.sql ПОСЛЕ того, как созданы таблицы public.games, public.content и public.hero_media (миграции v10 и v11).
4. В админке входите по email И паролю администратора. Пароль обязателен; роль admin должна быть назначена в profiles.
5. Раздел «Материалы игр»: выберите игру из списка, затем загрузите баннер, обложку или изображения галереи.
6. Раздел «Главный экран»: загрузите изображение. Для чистого фото включите «Только фотография». Чтобы добавить кнопку, выключите этот режим, заполните текст кнопки и URL. Заголовок и описание необязательны.
7. В публикации выберите игру из списка «Связать с игрой», добавьте фото, заголовок и краткое описание. Для слайда главной отметьте «Показывать на главном экране» и при необходимости заполните кнопку и ссылку.

Проверки: синтаксис JS и ZIP целостность. Реальное подключение к вашему Supabase не тестировалось. Если таблиц games/content/hero_media нет, сначала выполните соответствующие базовые миграции в порядке v10, затем v11, затем v14. Не публикуйте service_role ключ в браузерном config.js.
